# Geometry Calculator

A Python console exercise calculating circle area, rectangle area, and cylinder surface area.

## ✨ Highlights

- Prompts for radius, length, width, and height.
- Displays calculated results to two decimal places.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "calc.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [calc.py](calc.py)

## 📝 Project notes

Uses an approximate value of pi (`3.141`). The current source performs numerical calculations; it does not draw ASCII shapes.
